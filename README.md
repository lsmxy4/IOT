# Leafy · ESP32 스마트팜

사용자가 제공한 스마트팜 이미지의 구성을 기반으로 React·TypeScript 웹과 Arduino 펌웨어를 새로 만들었습니다.

## 현재 부품 구성

| 입력 / 출력 | 구현 |
|---|---|
| DHT11 | 온도·공기 습도 |
| 씨엔디아이 토양 습도 모듈 | AO 아날로그 입력, 건조/습윤 ADC 보정 후 상대 수분 % |
| 조도 센서 | 두 다리 LDR + 10kΩ, GPIO35 아날로그 입력 |
| Grove Water Level Sensor (10cm) | I²C 0x77 + 0x78, 20구간을 사용한 수위 % |
| 실제 물 펌프·환기 팬 | 구동 로직 구현, 전압/구동 모듈 미선정으로 기본 비활성화 |
| 일반 LED | 어두울 때 점등. 생육용 조명이 아닌 표시등 |

밝기는 ADC 상대값이며 lux가 아닙니다. 웹의 LED 점등 밝기 기준을 실측 후 설정합니다.

씨엔디아이 모듈은 정확한 상품 번호가 아직 없습니다. AO가 있는 모듈을 기준으로 구현했으며 정격 전원·출력 범위는 제품 표시로 확인해야 합니다. AO가 없는 제품이면 연결 방식 변경이 필요합니다.

## 폴더 구조

```text
IOT/
├─ react/                  # 새 스마트팜 대시보드
├─ arduino/
│  ├─ SmartFarm/           # Arduino IDE에서 SmartFarm.ino 열기
│  │  ├─ SmartFarm.ino
│  │  ├─ hardware_config.h
│  │  └─ secrets.example.h
│  ├─ src/                 # PlatformIO 기준 원본
│  ├─ platformio.ini
│  └─ export-arduino.ps1
└─ README.md
```

원본을 변경한 뒤 `powershell -ExecutionPolicy Bypass -File arduino/export-arduino.ps1`로 SmartFarm 복사본을 갱신합니다. 기존 secrets.h는 덮어쓰지 않습니다.

## 웹 실행

```powershell
cd react
npm install
npm run dev
```

[웹 대시보드](http://localhost:5173)는 기본적으로 `http://smartfarm.local`에 접속합니다. **환경 설정 → 데모 사용**을 누르면 실물 없이 시연할 수 있습니다. 데모는 실제 장치에 명령을 보내지 않습니다. 데모에서 **출력 활성화**를 누른 뒤 센서 조작을 펼치면 물 부족, 과열, 펌프 시간 제한을 확인할 수 있습니다.

웹 기능:

- 온습도, 토양 수분, 밝음/어두움, Grove 수위 표시
- 펌프·팬·LED의 자동/수동 제어, 전체 정지, 출력 활성화
- 급수 시작/종료 수분, 환기 온습도, 최소 수위, 펌프 최대 시간·대기 시간 설정
- 토양 ADC 원시값 확인 및 건조/습윤 기준 저장
- 최근 300개 수신 기록과 CSV 내보내기, 환경 경고·활동 기록
- 기본 2초 간격 조회(실제 간격은 네트워크 지연만큼 길어질 수 있음)
- 연결 해제 시 이전 수신값임을 표시하고 제어 비활성화

기록은 현재 브라우저 세션에만 존재합니다. 새로고침 또는 연결 모드 전환 시 초기화됩니다. 기준값·보정값은 보드 파일시스템에 저장합니다. 이전 실내 환경 설정은 새 설정 파일에 적용되지 않습니다.

```powershell
npm run build
npm test
```

## ESP32 NodeMCU ESP-32S 배선

기존 WeMos D1 배선은 제거하고 아래 GPIO 번호로 연결합니다. 보드의 P34는 GPIO34입니다.

| 장치 | ESP32 핀 |
|---|---|
| DHT11 DATA | GPIO4 (P4) |
| 토양 센서 AOUT | GPIO34 (P34, ADC1) |
| Grove 수위 SDA | GPIO21 (P21) |
| Grove 수위 SCL | GPIO22 (P22) |
| 두 다리 조도 센서 분압 중간점 | GPIO35 (P35) |
| 펌프 드라이버 IN | GPIO25 (P25), 기본 비활성화 |
| 팬 드라이버 IN | GPIO26 (P26), 기본 비활성화 |
| LED | GPIO13 → 330Ω → 양극, 음극 → GND |

센서는 3.3V 지원 여부를 확인해 3V3로 전원을 공급하고 GND를 공통 연결합니다. 토양 센서 출력이 0~3.0V로 확인되면 GPIO34에 직접 연결할 수 있습니다. 5V 신호는 넣지 마세요. ESP32 ADC는 11dB 감쇠를 사용하며, 웹 호환을 위해 10비트(0~1023)로 읽습니다. 새 보드에서 건조/습윤 값을 다시 보정해야 합니다. 이전 ESP8266의 27kΩ/10kΩ 분압은 이 조건에서는 필요하지 않습니다.

조도 배선: 3V3 → LDR → 중간점(P35) → 10kΩ → GND. 기존 330Ω은 LED 직렬 저항으로 사용합니다. 밝을 때와 가렸을 때 측정값 사이로 웹의 LED 점등 밝기 기준을 다시 저장하세요. 기존에 저장된 기준은 자동으로 변경되지 않습니다.

### Grove 수위

Grove Water Level Sensor는 두 I²C 장치에서 8+12 구간을 읽습니다. 펌웨어는 읽기 길이가 맞지 않으면 수위 오류로 처리하고 무한 대기하지 않습니다. 아래부터 연속으로 감지된 구간 수 × 5%를 표시합니다. 따라서 **센서 측정 높이의 비율**이며 물통의 리터·부피 비율은 아닙니다. 물 부족은 다음 센서 읽기에서 정지하고, 충분한 수위는 3회 연속 확인한 뒤 펌프를 허용합니다.

제조사 문서: [Grove Water Level Sensor](https://wiki.seeedstudio.com/Grove-Water-Level-Sensor/). 다른 제품인 Grove Water Sensor(누수 감지용)와 혼동하지 마세요. 첫 시운전 시 마른 상태와 담근 상태, 전원을 껐다 켠 상태에서 모두 값이 타당한지 확인하세요.

### 펌프·팬 구동

현재 **전압과 구동 모듈을 아직 정하지 않았기 때문에** `hardware_config.h`의 `MOTOR_DRIVER_CONFIGURED=false`입니다. 이 상태에서는 센서와 일반 LED만 동작하며 펌프·팬 핀은 입력 상태로 둡니다. 모터는 연결하지 마세요.

모터를 선정하면 다음을 맞춰야 합니다.

1. 펌프·팬의 정격 전압, 정상 전류와 기동/정지 전류에 맞는 별도 DC 전원
2. 3.3V 제어 신호에 맞는 MOSFET/모터 드라이버 또는 적절한 릴레이 모듈
3. DC 유도성 부하의 역기전력 보호, 전원 퓨즈, 부팅 시 OFF가 되는 입력 풀업/풀다운
4. 모듈의 작동 극성에 맞춰 `PUMP_ACTIVE_HIGH`, `FAN_ACTIVE_HIGH` 지정
5. 실제 배선과 OFF 동작을 확인한 뒤 `MOTOR_DRIVER_CONFIGURED=true`로 바꾸고 업로드

보드 3.3V·GPIO로 모터 전원을 공급하지 마세요. 비절연 MOSFET 드라이버는 보드와 전원 GND를 공통으로 연결하며, 절연 릴레이 모듈은 해당 모듈 결선도를 따릅니다. Arduino 공식 [모터 구동 안내](https://docs.arduino.cc/learn/electronics/transistor-motor-control/)를 참고하세요. 실제 부하 사양이 정해지기 전에는 단자별 모터 배선을 확정할 수 없습니다.

## Arduino IDE 업로드

1. ESP32 보드 패키지와 **DHT sensor library**, **Adafruit Unified Sensor**, **ArduinoJson 7.x**를 설치합니다. PlatformIO는 Espressif32 6.12.0을 사용합니다.
2. `arduino/SmartFarm/SmartFarm.ino`를 엽니다. `hardware_config.h`가 같은 폴더에 있어야 합니다.
3. `secrets.example.h`를 같은 폴더의 `secrets.h`로 복사하고 Wi-Fi 이름·비밀번호를 입력합니다. 기존 secrets.h가 있으면 그대로 사용합니다.
4. 보드는 **NodeMCU-32S** (없으면 ESP32 Dev Module) 기준으로 빌드했습니다. GPIO를 숫자로 지정하므로 D 별칭을 사용하지 않습니다. 파일시스템 공간이 있는 4MB 플래시 설정과 올바른 COM 포트를 선택합니다.
5. 업로드 후 시리얼 모니터 115200 baud에서 IP 또는 `http://smartfarm.local`을 확인합니다.
6. PC와 보드를 같은 Wi-Fi/핫스팟에 연결합니다. AP 기기 격리 또는 mDNS 차단이 있으면 연결이 안 될 수 있으며 IP 직접 입력으로도 확인할 수 있습니다.

PlatformIO:

```powershell
cd arduino
pio run
pio run --target upload
pio device monitor --baud 115200
```

API는 인증 없는 로컬 실습용입니다. 신뢰하는 로컬망에서 사용하고 인터넷에 포트를 공개하지 마세요. 웹은 로컬 HTTP 개발 서버로 열어야 HTTP 보드와의 혼합 콘텐츠 차단을 피할 수 있습니다.

## 제어 및 펌프 보호

- 부팅/재부팅 시 출력 비활성화. 웹 **출력 활성화**를 눌러야 시작합니다.
- 자동 급수: 토양 수분이 시작 기준 미만이면 ON, 종료 기준 이상이면 OFF.
- 토양 보정 전·토양 ADC 극단값·수위 통신 오류·물 부족 시 수동 모드에서도 펌프 금지.
- 펌프 최대 시간(기본 10초, 최대 30초)을 넘기면 정지하고 잠금. 자동 재시작하지 않습니다.
- 잠금 해제는 전체 정지 후 수위·토양 센서가 정상일 때만 가능. 해제해도 급수 후 대기 시간은 유지합니다.
- 정지 후 기본 60초 대기. 반복 ON 요청이나 모드 변경으로 작동 타이머·대기 시간을 초기화하지 않습니다.
- 팬: 온도 또는 습도가 기준 이상이면 ON, 둘 다 복귀 기준 아래이면 OFF. DHT 오류 시 OFF.
- 일반 LED: LDR DO의 어두움 신호로 ON. 입력 3회 안정화를 거칩니다. DO 신호만으로 단선과 정상 밝음을 완전히 구분할 수는 없습니다.
- 수동 모드에서 웹 요청이 10초 이상 없으면 전체 정지합니다. 자동 모드는 Wi-Fi와 별개로 계속 동작합니다.
- **전체 정지는 소프트웨어 명령입니다.** 통신이 끊기면 전달할 수 없으므로 실물의 전원 차단 수단을 마련하세요. 루프/통신 지연 때문에 시간 제한은 하드웨어 수준의 정확한 차단 보장이 아닙니다.
- 출력 상태는 요청한 전기적 제어값이며 실제 회전·유량 피드백이 아닙니다.

## 토양 센서 보정

환경 설정에서 현재 ADC를 확인합니다. 건조한 토양과 충분히 젖은 토양에서 각각 안정된 값을 기록하고 **제어 기준 설정 → 토양 센서 보정**에 입력합니다. 두 값의 차이는 50 이상이어야 합니다. 실측을 마친 뒤 보정 완료를 체크하고 저장합니다. 이 수치는 상대 수분이며 절대 체적 수분 함량이 아닙니다. 개방된 아날로그 선은 정상 범위처럼 보일 수 있으므로 현장에서 단선 시험도 필요합니다.

## API

모든 성공 응답은 `schema: smartfarm-v1` 상태 JSON이며, 다른 스키마의 펌웨어 응답은 웹에서 거부합니다.

| 경로 | 메서드 / 본문 |
|---|---|
| `/api/status` | GET, 상태 및 수동 모드 heartbeat |
| `/api/settings` | POST, 웹 설정 객체 전체 |
| `/api/mode` | POST `{"auto":true}` |
| `/api/arm` | POST `{"armed":true}` |
| `/api/stop` | POST `{}` |
| `/api/outputs` | POST `{"pump":true}`, `{"fan":true}`, `{"light":true}` 중 하나 |
| `/api/pump/reset` | POST `{}` |

## 현장 검증

먼저 모터를 연결하지 않고 센서, LED, 웹 설정 저장을 확인합니다. 그다음 선정한 모터 드라이버와 외부 전원으로 OFF 극성·부팅 OFF·전체 정지를 확인합니다. 물 부족/수위 분리, 토양 센서 분리, 최대 시간 잠금, 잠금 해제 후 대기 시간, 수동 모드 통신 중단을 차례로 시험하세요. 실제 장비 테스트는 이 개발 환경에서 수행하지 않았습니다.


### 수동 LED 제어

수동 모드에서는 출력 활성화 없이 LED 스위치로 직접 ON/OFF 할 수 있습니다. 조도 센서 상태는 수동 LED를 제한하지 않습니다. 펌프·팬의 출력 활성화와 보호 조건은 유지됩니다. 전체 정지 또는 수동 통신 10초 중단 시 LED도 꺼집니다.
